State Transitions (No Navigation)

The modal uses a Step type with 5 states, all managed via React state:

type Step = 'userCode' | 'authCode' | 'selectMerchant' | 'selectCatalog' | 'success'

Flow progression:

  • userCode → (user enters auth code) → exchangeIFoodAuthCode() → selectMerchant
  • selectMerchant → (user selects merchant) → getMerchantCatalogs() → selectCatalog
  • selectCatalog → (user selects catalog) → completeIFoodConnection() → success
  • success → (user clicks Concluir) → modal closes

✅ All transitions use setStep(), never router.push() or window.location

API Integration Verification

The modal calls these server actions (all defined in src/features/ifood/api.ts):

  • ✅ initiateIFoodOAuth(storeId) - Returns userCode and verificationUrl
  • ✅ exchangeIFoodAuthCode(storeId, authCode) - Returns merchants list
  • ✅ getMerchantCatalogs(storeId, merchantId) - Returns catalogs list
  • ✅ completeIFoodConnection(storeId, merchantId, catalogId, catalogName, merchantName) - Saves connection

All server actions have been verified in Feature #16, #18, #19, #20.
