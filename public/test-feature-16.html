Feature #16: iFood Connection Data Verification

This page tests that completeIFoodConnection stores data correctly in ifood_integrations table.

Results:

Verification Checklist:

  • merchant_id field contains selected merchant's ID
  • catalog_id field contains selected catalog's ID
  • catalog_name field contains selected catalog's display name
  • merchant_name field contains merchant display name
  • status field is 'connected'
  • access_token is encrypted (not plaintext)
  • refresh_token is encrypted (not plaintext)
  • token_expires_at is set
